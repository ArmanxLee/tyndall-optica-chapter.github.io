# Tyndall Optica Student Chapter

Website for the UCC × Tyndall Optica Student Chapter.

## GitHub Pages

1. Create a GitHub repository named `tyndall-optica-chapter.github.io`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. Your site will be available at:

## Before publishing

In `index.html`, replace:
- the `#` on the **Join the chapter** button with the Google Form URL;
- the Instagram `#` with Optica/SPIE Instagram URL;
- the LinkedIn `#` with LinkedIn URL;
- `YOUR_EMAIL_HERE` with the chapter email;
- the placeholder event section with real events.

You can also add UCC/Tyndall/chapter logos later.
